# 坦克大战 Battle City 🎮

一个用原生 HTML + Canvas + JavaScript 实现的经典坦克大战（Battle City）网页游戏。零依赖，单文件 `index.html`，双击即可游玩。

## 玩法

- 控制你的黄色坦克，**守住底部的基地（鹰）**，消灭关卡内全部 20 辆敌军坦克即可过关。
- 敌军从顶部三个位置不断刷新（场上最多 4 辆），会朝你移动、开火，并伺机攻击基地。
- 你有 3 条命，基地被毁或命数耗尽则游戏结束。
- 砖墙可被子弹摧毁，钢铁墙需要强化火力才能击穿，水塘坦克无法通行（子弹可穿过），树丛会遮挡坦克。

## 操作

| 按键 | 功能 |
| ---- | ---- |
| `方向键` / `WASD` | 移动 |
| `空格` / `J` | 开火 |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |
| `M` | 静音 / 开启音效 |

## 特性

- 4 种敌军：**普通**（灰）、**快速**（绿）、**火力**（红）、**装甲**（4 血，随掉血变色）
- 闪烁的红色敌军被击毁后掉落道具：
  - ⭐ 星：强化火力（更快、可双发、最终可击穿钢铁）
  - 🛡 头盔：获得 10 秒护盾
  - 💣 手雷：消灭场上所有敌军
  - 🚙 坦克：增加一条命
  - ⏱ 定时器：冰冻敌军 10 秒
- 3 个关卡（砖墙、水塘、钢铁、树丛组合），通关后获胜
- 分数、最高分、生命、敌军剩余数实时显示
- 复古像素风，含简单音效（Web Audio，无需外部资源）

## 运行

方式一：直接用浏览器打开 `index.html`。

方式二（启用 GitHub Pages 后）：访问 `https://<你的用户名>.github.io/tank-battle/`。
